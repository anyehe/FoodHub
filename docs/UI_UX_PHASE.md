# FoodHub UI/UX Enhancement Phase

## Goal
Make the FoodHub customer experience more attractive and easier to scan while preserving the existing FoodHub brand palette and Bootstrap/Flutter architecture.

## Web changes
- Refreshed typography with DM Sans and Plus Jakarta Sans.
- Stronger visual hierarchy for hero sections, section headings and prices.
- More prominent primary calls to action.
- Rounded cards, chips and buttons with consistent spacing.
- Food/product presentation cards with visual placeholders when an image is unavailable.
- Category discovery cards.
- Branch selection presentation.
- Improved footer and social-link treatment.
- Responsive behavior retained for desktop and mobile widths.
- Operations pages inherit the same design tokens through the shared Blade layout.

## Flutter changes
- Material 3 theme aligned to FoodHub colors.
- Improved app bar branding.
- Branded discovery hero.
- Category chips.
- More attractive product cards.
- Floating cart count and notifications/order actions.
- Improved empty/error/retry presentation.

## Design principle
The customer-facing experience should feel food-first: clear imagery or visual placeholders, short descriptions, prominent pricing, obvious actions and minimal friction from discovery to checkout. Staff-facing screens should remain information-dense but use the same design tokens so the platform still feels like one product.
