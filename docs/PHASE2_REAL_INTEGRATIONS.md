# FoodHub Phase 2 — Real Integrations

## Scope

Phase 2 connects FoodHub to external services while keeping the application safe when credentials are not configured.

### Implemented integration boundaries

- PayPal REST Orders integration: OAuth token acquisition, order creation, capture and refund-ready adapter.
- GCash adapter: configurable checkout endpoint; provider-specific URL and secret remain environment configuration because merchant API contracts vary.
- Firebase Cloud Messaging HTTP v1: service-account OAuth assertion, device registration, push delivery with failure isolation.
- Google Maps: geocoding and directions URL generation.
- SMS: generic bearer-token provider adapter so a selected SMS vendor can be configured without changing business logic.
- Laravel broadcasting/Reverb: broadcast configuration, authenticated order channels and order status events.
- Flutter Firebase Messaging: optional initialization, permission request, device-token registration and token refresh handling.
- Email notifications: database + mail channels; local `MAIL_MAILER=log` keeps development safe.

## Configuration

Copy values into `.env` only after obtaining provider credentials. Never commit credentials, Firebase service-account JSON, private keys or production secrets.

### PayPal

```text
PAYPAL_MODE=sandbox
PAYPAL_CLIENT_ID=
PAYPAL_SECRET=
PAYPAL_CURRENCY=PHP
PAYPAL_RETURN_URL=
PAYPAL_CANCEL_URL=
```

Use sandbox first. Switch `PAYPAL_MODE=live` only after end-to-end acceptance testing.

### GCash

```text
GCASH_SECRET=
GCASH_CHECKOUT_URL=
GCASH_RETURN_URL=
GCASH_CANCEL_URL=
```

The adapter deliberately does not assume a proprietary GCash merchant API shape. The exact endpoint/payload supplied by the merchant account must be configured and then tested against its webhook contract.

### Firebase

```text
FIREBASE_PROJECT_ID=
FIREBASE_CLIENT_EMAIL=
FIREBASE_PRIVATE_KEY=
FIREBASE_SERVICE_ACCOUNT_JSON=
GOOGLE_APPLICATION_CREDENTIALS=
```

Prefer `GOOGLE_APPLICATION_CREDENTIALS` or another protected service-account source. The server sends through FCM HTTP v1 and never stores service-account credentials in the database.

### Google Maps

```text
GOOGLE_MAPS_KEY=
```

Enable the required Google Maps Platform API and billing for the project before live requests.

### SMS

```text
SMS_PROVIDER_URL=
SMS_PROVIDER_TOKEN=
```

### Reverb

```text
BROADCAST_CONNECTION=reverb
REVERB_APP_ID=
REVERB_APP_KEY=
REVERB_APP_SECRET=
REVERB_HOST=127.0.0.1
REVERB_PORT=8080
REVERB_SCHEME=http
```

Install dependencies with Composer and run the Reverb server before enabling this in a local environment.

## Safety behavior

Missing credentials do not make checkout silently appear successful. Gateway initiation returns a configuration error until the provider is configured. FCM failures are logged without failing order creation/status transitions. Email uses the configured Laravel mailer.

## Runtime commands

```bat
composer install
php artisan optimize:clear
php artisan migrate
php artisan test
php artisan reverb:start
```

For Flutter:

```bat
flutter pub get
flutterfire configure
flutter analyze
flutter build apk --debug
```

Firebase native configuration files generated by FlutterFire are environment-specific and are intentionally not bundled with the source build.
